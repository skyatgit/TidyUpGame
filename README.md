# TidyUp Game

一个基于 React + Vite 构建的休闲拖拽整理小游戏。玩家需要在 10×10 的房间中挑选未被遮挡的物品，拖动到下方的箱子中完成打包，用更少时间清空房间来获取高分。

## ✨ 特性
- **纯前端生成主题**：通过本地算法随机生成房间主题、背景与物品信息。
- **多语言支持**：内置中文与英文文案，可在开始界面切换语言。
- **拟物拖拽体验**：支持鼠标与触摸操作，可通过 `R` 键或滚轮旋转物体。
- **箱子管理**：三个活跃箱位配合排队区，填满后可打包清空继续使用。

## 🚀 快速开始
```bash
npm install
npm run dev
```
- 默认开发服务器运行在 `http://localhost:3000`。
- 构建发行版：`npm run build`，随后可用 `npm run preview` 本地预览。

> 建议使用 Node.js 18+ 以匹配 Vite 与 React 19 的依赖要求。

## 🕹️ 玩法概览
1. 点击“开始整理”生成当前关卡的主题与物品。
2. 只能拖动最上层（未被其它物品遮挡）的物品。
3. 将物品拖入底部箱子网格，放置位置会实时提示是否合法。
4. 箱子填满后点击“打包”可获得额外积分并腾出空位。
5. 当房间中所有物品都被装箱即算完成，可继续进入下一关。

## 🧱 项目结构
```
├── App.tsx              # 游戏主界面与状态逻辑
├── components/          # 物体与箱子等可复用组件
├── services/geminiService.ts # 随机关卡与物品生成逻辑
├── types.ts             # TypeScript 类型定义
├── locales.ts           # 多语言翻译文案
├── index.tsx / index.html
└── vite.config.ts
```

## 🛠️ 技术栈
- React 19 + TypeScript
- Vite 6 开发与打包
- Tailwind CSS CDN 版本（直接在 `index.html` 中注入）
- `uuid` 用于生成物品与箱子 ID
